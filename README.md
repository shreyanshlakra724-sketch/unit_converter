# UNIT CONVERTER

A web-app based converter with various conversions such as computer conversion(storage conversions), unit conversion(weight conversions, scale conversions), currency conversions and scientfic conversions(temprature scale)

Built with vanilla html,css and javascript.
For currency used frankfurter api.(https://frankfurter.dev)
